# ⚠️ THIS REPOSITORY IS PUBLIC — read before every change

`github.com/calyptasapps/calyptasapps` is **public**. Anyone on the internet can read every file **and the full
commit history**. Deleting a file later does NOT remove it from history.

Before you create, commit or push anything, check whether it would expose:

- **Secrets:** API keys, tokens, passwords, `.env` files, signing keystores, service-account JSON, OAuth client secrets.
- **Private business data:** revenue, earnings, install or analytics numbers, Play Console / AdMob / Vercel screenshots
  or exports, user feedback containing user details, ad unit IDs other than what `public/app-ads.txt` already shows.
- **Personal data:** legal names, home addresses, phone numbers, personal email addresses, ID documents.
- **Internal material:** unreleased plans, private app source code, internal notes, local machine paths
  (e.g. `/Volumes/...`, `/Users/...`).
- **Assets without rights:** photos, music, fonts or icons that are not licensed for public redistribution.

**If anything you are about to commit matches the list, or you are unsure: STOP and tell the owner first.**
Say exactly what would become public and why, and wait for an explicit "yes". Never commit it silently, and never
"fix it later". Private material belongs in the private app repositories (e.g. NewCollagic) or outside git.

Safe by default: the marketing pages, public store copy, approved screenshots/promo media, `app-ads.txt`,
the privacy policy, and the public support email `calyptasapps@gmail.com`.
